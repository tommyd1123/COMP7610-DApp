## 老师要的 DApp 是什么

要交的是一个能在浏览器里点、能用钱包签名、能在以太坊测试网上改合约状态的应用。只做一个好看的网页，或者只在 Remix 里点部署，都不够。

必须同时有这六样：

1. 浏览器前端：HTML、CSS、JavaScript。React、Vue 或纯 JS 都可以。
2. 智能合约：规则放在链上，不放在你们自己的服务器里。
3. Ethers.js：前端靠它读合约、发交易。
4. 钱包：MetaMask 或同类钱包，用来管账户和签名。前端不能保存私钥。
5. 至少一笔和产品有关的链上操作。要有交易哈希，在区块浏览器里打得开。只查询余额不算。
6. 网络用 Sepolia。其他以太坊测试网也可以。不要用主网真钱。

老师给的例子是「每个钱包领一张 NFT 票」。这是教学示例。小组可以沿用这个方向，但要加上自己的故事和规则。原样交教程，看不出小组自己的工作。

## 报告五章分别写什么

| 章节 | 写什么 |
| --- | --- |
| Background | 这个问题从哪来，为什么适合放到链上 |
| Idea | 一句话产品、用户是谁、用户做的一件事 |
| Design | 架构、合约负责什么、页面有哪些、谁能调用哪个函数 |
| Implementation | 技术栈和版本、测试网、合约地址、怎么跑、已知限制 |
| Contribution distribution | 每个组员做了什么。要能对上仓库里的文件或提交记录 |

PDF 把 distribution 写成了 `distibution`，意思就是分工。
