# 五人分工与报告

每人改自己的目录，通过 Pull Request 合进 `main`。不要五个人同时改 `src/App.jsx`。

名字先空着。组长把姓名和 UID 填进下表，再发给组员。

| 编号 | 姓名 / UID | 角色 | 主要目录 |
| --- | --- | --- | --- |
| 1 | （组长填写） | 集成：环境、合并、README、演示彩排 | 仓库根目录、`.env.example`、`src/config/` |
| 2 | | 合约 | `contracts/` |
| 3 | | 钱包与交易 | `src/wallet/` |
| 4 | | 前端界面 | `src/App.jsx`、`src/ui/`、样式 |
| 5 | | 报告与演示，另外负责链上只读状态 | `docs/report/`、`src/chain/` |

成员 5 不能只写文档。PDF 要求每个人都有贡献。只读状态（例如「这个地址领过没有」）是一块独立的小代码，和发交易的人分开，避免两个人抢同一个函数。

## 本周先做的三件事

产品故事还没定。在定下来之前，不要开始大改页面文案。

1. 五个人都装 MetaMask，切到 Sepolia，领到测试 ETH。水龙头用 <https://ethereum.org/developers/docs/networks/#sepolia> 列表里的。
2. 各自分头读 `docs/00-这份作业是什么.md` 和 `docs/01-教授给的框架和代码.md`。想看能跑的完整例子，克隆老师仓库，不要在本仓库里把教程填完就当作业交了。
3. 开一次短会，定下一句话：用户是谁，他在链上做的那一件事是什么。把这句话写进 `docs/report/大纲.md` 的 Idea。

如果决定继续做「领票」，要在教程之外加上小组自己的规则，例如活动名称、核销、转让限制。原样提交老师示例，报告里写不出你们改了什么。

## 每个人的完成标准

### 1. 组长 / 集成

- README 里的命令，换一台电脑能把页面打开。
- `.env` 没有被提交。合约地址只出现在 `.env`，例子放在 `.env.example`。
- 合约部署后，把 Sepolia 合约地址和一笔成功交易的链接记进 README。
- 合并别人的分支前，自己先 `npm run dev` 点一遍。

### 2. 合约

- `contracts/` 里有小组自己的 Solidity，并说明它和老师示例差在哪。
- 用 Remix 部署到 Sepolia，把合约地址交给组长。不要部署到 Remix VM。
- 在报告 Implementation 里写：编译器版本、网络、合约地址、核心函数、一次失败会怎样（例如重复领取）。

### 3. 钱包与交易

改 `src/wallet/ethereum.js`。对照教程第 6–10 页，实现：

- 检测 MetaMask
- 切到 Sepolia（链 ID `0xaa36a7`）
- 连接账户
- 用户确认后发送会改状态的交易，返回交易哈希，并等待打包
- 账户切换时通知页面

页面上的按钮已经会调用这两个函数。现在点下去会看到「还没实现」，这是预期的。

### 4. 前端界面

- 没连钱包、交易进行中、成功、用户拒绝、合约报错，这几种状态都要有一句人能看懂的话。
- 成功后给出 Etherscan 链接，哈希和钱包里的是同一笔。
- 样式放在 CSS 或 `src/ui/`，不要把钱包逻辑写进页面文件。

### 5. 报告、视频、只读状态

- 按 `docs/report/大纲.md` 收齐五章，最后导出 PDF。
- 英文视频不超过 15 分钟，里面有现场演示。分镜写在报告目录里。
- 在 `src/chain/` 实现只读查询（教程里的 `hasMinted` 就是这种调用）。只读不弹确认窗。

## 报告谁写哪一章

成员 5 负责收成一份 PDF。其他人交自己那几段，不各自交一份报告。

| 章节 | 主笔 | 其他人提供 |
| --- | --- | --- |
| Background | 5 | 全组用三句话说明「为什么不放在普通数据库」 |
| Idea | 1 组织，5 落笔 | 会上定下的那句话和用户场景 |
| Design | 5 汇总 | 2 画合约函数，4 画页面，3 标出哪一步要签名 |
| Implementation | 5 统稿 | 2、3、4 各写自己的目录、命令和限制 |
| Contribution distribution | 5 收表 | 每人自己写一行，并附上能核对的文件或提交 |

分工表用这个格式：

| 姓名 / UID | 角色 | 做了什么 | 能核对的产出 |
| --- | --- | --- | --- |
| | | | 路径、合约地址或交易链接 |
