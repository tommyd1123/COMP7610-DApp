### 现在怎么做

一个学生社团要办一场免费讲座。同学现在用在线表格报名。名单在社团干部的表格里，不在公开的链上。

### 会出什么事

1. 干部可以事后加上或删掉某一个人，其他同学看不到这次修改。
2. 如果报名系统没有重复检测，同一个人可能重复报名。
3. 同学要向别人证明自己报上了名，只能发一张表格截图。别人无法自己核对。
4. 临时不能参加时，转让资格或退回名额需要干部修改名单，同学无法独立核对处理结果。

### 三个页面与合约共同执行的规则

同学有空位才能领票，每个地址最多持有一张有效票。未核销票可以转给另一合资格地址，入场资格跟随当前所有者；也可以退回部署者，释放一个名额，下一位同学领取时复用这张票。部署者按票号核销当前持有人，核销后保留纪念票，禁止转让、退票和重复入场。这些操作都计划留在 Sepolia 上。

这些规则还在空位里，还没有写进合约。

### 挡不住什么

- 一个人可以换一个钱包再领，所以不是「一个人一张」。
- 票没有图片。链上记下的是票号和主人地址。
- 票不收费。用户付的是测试网手续费。
- 只能证明链上票的归属和核销记录，无法独立确认线下到场身份；主办方仍负责现场核验。

## Idea

同学领取一张座位有限的讲座票，可以转给另一同学或退回主办方，主办方按票号核销当前持有人。

> Students claim a free seminar ticket, transfer it to another student, or return it to the organizer so the seat can be claimed again. The organizer checks in the current ticket holder once.

顺序见 `README.md` 的「故事」。
