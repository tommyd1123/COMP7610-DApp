## 三条线怎么接在一起

```text
用户点按钮
    ↓
src/App.jsx          页面
    ↓
src/contract.js      地址 + ABI + 链 ID
    ↓
ethers.js            把函数调用编成交易
    ↓
MetaMask             用户用私钥签名，网页拿不到私钥
    ↓
Sepolia              合约 TicketNFT.mint() 改链上状态
    ↓
Etherscan            用交易哈希核对
```

读状态（`hasMinted`）不弹确认、不花 gas。写状态（`mint`）会弹 MetaMask，要花少量测试网 ETH 当 gas。票本身不收费。

## 合约：`contracts/TicketNFT.sol`

来源：老师示例仓库。编译器 `^0.8.30`。OpenZeppelin 版本钉在 `5.6.1`，这样每个人在 Remix 里编译到的是同一份库。

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.30;

import {ERC721} from "@openzeppelin/contracts@5.6.1/token/ERC721/ERC721.sol";

contract TicketNFT is ERC721 {
    uint256 private _nextTokenId = 1;
    mapping(address => bool) public hasMinted;

    event Mint(address indexed minter, uint256 indexed tokenId);

    constructor() ERC721("Ticket NFT", "TICKET") {}

    function mint() external returns (uint256 tokenId) {
        require(!hasMinted[msg.sender], "One ticket per wallet");

        tokenId = _nextTokenId;
        _nextTokenId += 1;
        hasMinted[msg.sender] = true;
        _safeMint(msg.sender, tokenId);
        emit Mint(msg.sender, tokenId);
    }
}
```

这段合约做的事：

- 继承 ERC-721。每个 token ID 独一无二，有一个主人。
- `hasMinted` 记下这个地址领过没有。Solidity 会自动生成一个只读函数 `hasMinted(address)`。
- `mint()` 只能从外部调用。已经领过就回退，整笔交易作废。
- 成功时发出 `Mint` 事件。ERC-721 自己还会发出 `Transfer`。

部署时用 Remix，环境选 MetaMask 注入的 Sepolia。不要部署到 Remix VM，那个地址前端连不上。

## 前端配置：`src/contract.js`

来源：老师示例仓库，和教程第 3 页一致。

```javascript
export const CONTRACT_ADDRESS = import.meta.env.VITE_CONTRACT_ADDRESS ?? "";

export const TICKET_ABI = [
  "function mint() returns (uint256 tokenId)",
  "function hasMinted(address account) view returns (bool)",
  "event Mint(address indexed minter, uint256 indexed tokenId)",
];

export const SEPOLIA_CHAIN_ID = "0xaa36a7";
export const SEPOLIA_EXPLORER_URL = "https://sepolia.etherscan.io";
```

- `VITE_CONTRACT_ADDRESS` 是部署之后的合约地址，写在 `.env` 里。它是公开的。不要把私钥写进任何 `VITE_` 变量。
- ABI 只列出页面真正要调用的函数。合约一改，这里要跟着改。
- `0xaa36a7` 就是 Sepolia 的链 ID `11155111`。

## 教程第 6–10 页的五个函数

这些是老师 PPT 上的写法。示例仓库里的 `App.jsx` 比这更完整（多了错误提示和读取 `hasMinted`）。本仓库把它们留成空位，由对应的人填进 `src/wallet/ethereum.js`。

### 1. 拿到 MetaMask

```javascript
function getProvider() {
  if (!window.ethereum) throw new Error("Install MetaMask to continue");
  return new BrowserProvider(window.ethereum);
}
```

### 2. 切到 Sepolia

```javascript
async function ensureSepolia() {
  const currentChainId = await window.ethereum.request({ method: "eth_chainId" });
  if (currentChainId === SEPOLIA_CHAIN_ID) return;
  await window.ethereum.request({
    method: "wallet_switchEthereumChain",
    params: [{ chainId: SEPOLIA_CHAIN_ID }],
  });
}
```

### 3. 连接钱包

```javascript
async function connectWallet() {
  const provider = getProvider();
  const accounts = await provider.send("eth_requestAccounts", []);
  await ensureSepolia();
  setWalletAddr(accounts[0]);
}
```

连接只是拿到公开地址，还没有发交易。

### 4. 铸造

```javascript
async function mint() {
  await ensureSepolia();
  const provider = getProvider();
  const signer = await provider.getSigner();
  const contract = new Contract(CONTRACT_ADDRESS, TICKET_ABI, signer);
  const transaction = await contract.mint();
  setTransactionId(transaction.hash);
  setHintText("Transaction submitted. Waiting for confirmation...");
  await transaction.wait();
  setClaimedNft(true);
  setHintText("Ticket minted successfully!");
}
```

`wait()` 要等交易被打包，不是一点按钮就算成功。

### 5. 监听换账户

```javascript
useEffect(() => {
  if (!window.ethereum) return undefined;
  const AccountChanged = (accounts) => {
    const nextAccount = accounts[0] || "";
    setWalletAddr(nextAccount);
    setTransactionId("");
    setHintText("");
  };
  window.ethereum.on("accountsChanged", AccountChanged);
  return () => {
    window.ethereum.removeListener("accountsChanged", AccountChanged);
  };
});
```

## 示例仓库多出来、教程 PPT 没展开的部分

这些在老师仓库的 `src/App.jsx` 里，读的时候一起看：

- `isAddress(CONTRACT_ADDRESS)`：地址没填时，页面提示先写 `.env`。
- `refreshMintStatus()`：用 provider 调用 `hasMinted`，不弹钱包。
- `readableError()`：用户在 MetaMask 里拒绝时，给出能看懂的句子。
- `chainChanged`：切换网络后刷新页面。
